Formato esperado do JSON

O arquivo tem três partes: total (votos somados), mun (código TSE do município → nome, votos e nº de seções) e sections (uma entrada por seção de votação com voto). Campos opcionais de identificação: candidato, numero, cargo, eleicao e estado.

  "total": 4876,
  "candidato": "Profª Ju Andózio",      // opcional
  "numero": "1333",                     // opcional
  "cargo": "Deputada Federal",          // opcional
  "eleicao": "Eleições 2026 · 1º turno",// opcional
  "mun": {
    "81051": { "nome": "FLORIANÓPOLIS", "votos": 1745, "secoes": 789 }
  },
  "sections": [
    { "muni": "81051", "muni_nome": "FLORIANÓPOLIS", "zona": "100",
      "secao": "313", "votos": 1,
      "local": "E.E.M. JACÓ ANDERLE", "end": "RUA FRANCISCO FAUSTO MARTINS, S/N" }
  ]
}
Os pontos são posicionados por sorteio determinístico dentro do polígono do município da seção (a mesma seção aparece sempre no mesmo ponto). Malha municipal: IBGE (espelho tbrugz/geodata-br). Interação: scroll dá zoom · arrastar move o mapa · duplo clique volta à visão completa.
